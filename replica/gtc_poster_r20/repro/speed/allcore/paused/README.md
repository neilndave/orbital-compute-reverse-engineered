# All-core timing window (paused render)
Timing logs and JSON results of the 20-core CPU, 1-core CPU and GPU runs taken in one clean window while a long render was paused.
Machine-specific process listings (`PS_*.txt`, `PG_*.txt`) are not published; home-directory prefixes in the logs are shown as `<HOME>`.
The numbers used on the poster are in `../../SPEED_ALLCORE_R11.json`.
